# TianMingNanWei Homebrew Tap

Homebrew formulae for [Glance CLI](https://github.com/TianMingNanWei/glance-cli), a live Apple silicon system monitor for the terminal.

## Install

```sh
brew install tianmingnanwei/tap/glance
```

Or tap once, then install by name:

```sh
brew tap tianmingnanwei/tap
brew install glance
```

## Upgrade

```sh
brew update
brew upgrade glance
```

## Formulae

| Formula | Description |
| --- | --- |
| [`glance`](Formula/glance.rb) | Live Apple silicon system monitor for the terminal |
